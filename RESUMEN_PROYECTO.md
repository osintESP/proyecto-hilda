## 🔧 CÓMO FUNCIONA

### Arquitectura
```
Usuario
  ↓
index.html (UI)
  ↓
app.js (Coordinador)
  ├→ gamification.js (Puntos/Niveles)
  ├→ motor-exercises.js (Ejercicios Motores)
  ├→ cognitive-exercises.js (Ejercicios Cognitivos)
  ├→ hand-detection.js (MediaPipe)
  └→ utils/ (Storage, Audio, Notificaciones)
  ↓
LocalStorage (Persistencia)
```

### Flujo de Ejercicio
1. Usuario selecciona ejercicio
2. Se abre modal con setup
3. Ejercicio ejecuta lógica
4. Se registran métricas
5. Se calculan puntos
6. Se actualiza progreso
7. Se desbloquean insignias
8. Se guarda en LocalStorage
